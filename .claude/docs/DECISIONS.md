# Owner decisions

Every decision the owner took on WebKit 6.0, one row each, so none slips. The rule that keeps it current is in [`.claude/rules/git-workflow.md`](../rules/git-workflow.md): a change that records or implements an owner decision adds or updates its row here in the same change.

Status is one of **done** (in the code or the docs), **open** (decided, not finished), **deferred** (decided to do later; the roadmap holds it) or **needs owner** (waits on an answer or an action only the owner can give). "Where" names the commit or file that holds it. Deferred and open items are also listed in [`ROADMAP.md`](../../ROADMAP.md) (M2.13, "Deferred and open").

This register starts from the review of 12–16 November 2026 (185 rows: 170 done, 3 open, 7 deferred, 5 needs owner; updated 2026-11-16 with the owner's answers on APCA, the Eyebrow orange, code owners and 1Password).
