# Changelog

From 6.0 the four packages in this repository (`@aziontech/webkit`, `@aziontech/theme`,
`@aziontech/icons`, `@aziontech/webkit-mcp`) share one version and one `vX.Y.Z` tag, and every
release is recorded here. release-please writes each entry from the commits merged into `main`.

The history before 6.0 is in each package's own changelog:
[`packages/webkit`](./packages/webkit/CHANGELOG.md), [`packages/theme`](./packages/theme/CHANGELOG.md)
and [`packages/icons`](./packages/icons/CHANGELOG.md).

## [5.13.0](https://github.com/aziontech/webkit/releases/tag/%40aziontech%2Fwebkit%405.13.0) (2026-11-17)

The last release with one version per package: `@aziontech/webkit` 5.13.0, `@aziontech/theme` 5.2.2,
`@aziontech/icons` 4.5.0 (`@aziontech/webkit-mcp` was not published yet). The shared history starts
after this commit.
