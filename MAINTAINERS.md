# Maintainers

The people and teams who own `aziontech/webkit` and its four npm packages (`@aziontech/ui`,
`@aziontech/theme`, `@aziontech/icons`, `@aziontech/ui-mcp`). They review and merge pull
requests, cut releases and answer security reports with the security office.

| Maintainer          | Role                                                    |
| ------------------- | ------------------------------------------------------- |
| @aziontech/team-uxe | Owning team: components, theme, icons, docs and release |
| @robsongajunior     | Lint rules, lint canaries and the ESLint configuration  |

Review rules live in [`CODEOWNERS`](./CODEOWNERS): changes to `.github/`, `CODEOWNERS` and the
security tool configuration also need `@aziontech/oss-review`, and the security files need
`@aziontech/security-office`. Security reports go to security@azion.com, see
[`SECURITY.md`](./SECURITY.md).
