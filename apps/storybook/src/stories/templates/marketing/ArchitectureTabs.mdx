# ArchitectureTabs

A band that plots several architectures of one product, one at a time. Up to five tabs lie in a row, each with its own title, description and progress, and the active tab's diagram runs the full width above or below them. The tabs are held at `size="small"`, so five titles fit the row without the band growing. The AI Gateway page uses it for its routing architectures, with the tabs at the bottom.

The tabs advance on a timer. It pauses under the pointer or keyboard focus, and never runs under reduced motion.

The band is the `ArchitectureTabs` component from `@aziontech/webkit/architecture-tabs`; it composes `SectionModule`, `SectionTitle`, `Button`, `FrameBox`, `MediaTabs` and `Diagram`.

### Default

The routing band from AI Gateway: Request path, Provider failover, Cost routing, Latency routing and Response cache, each held for 6 seconds. Each tab draws one of webkit's named diagrams (`ai-gateway`, `ai-gateway-provider-failover`, `ai-gateway-model-routing`, `ai-gateway-latency-routing`, `ai-gateway-response-cache`), named by each tab's `diagram`.

##### Use it on the site

Add this entry to the `sections` array of the page JSON. `_id` picks the block and `props` are bound straight onto the component:

- `eyebrow`, `title` and `description` make the section title.
- `position` is the side of the diagram the tabs sit on: `top` (the default), `bottom`, `left` or `right`. Left and right hold up to three tabs.
- `tabs` are up to five architectures, each a `value`, a `title`, a `description` and the `diagram` name it draws.
- `primaryAction` is the large button in the section title, a `label`, an `href` and `trailing`. Leave it out to drop the button.
- `anchor` is the band's id for in-page links.

Example:

### Platform

The base Azion architecture the website bundle plots: Request path, Security first, Code at the edge, Data close by and Every request seen. Each tab draws one product's starter diagram from webkit by name (`workloads`, `firewall`, `functions`, `sql-database`, `real-time-events`), so the band reads as one request crossing the platform.
