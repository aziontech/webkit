A claim beside the code that makes it true: copy on one side, a code sample on the other, on one frame. Product pages use it when the argument is a config or a handler a developer can read, like Functions and Application Accelerator.

The code sits in a wrapper with its own radius, so the wrapper casts the shadow. The tabs are declared in the script, so the code stays verbatim.

Built from `SectionModule`, a `framed` `MediaSplit` or a `FrameBox`, and `CodeBlock`, with buttons or a recipe list on the copy side.

### Default

From the Functions page: a two-tab code sample on the pixelate texture, cut off by the frame's bottom rule, with two actions. With two destinations the band is not a link itself, so the reader picks a button.

<Canvas of={CodeSplitStories.Default} />

##### Use it on the site

Add this entry to the `sections` array of the page JSON. `_id` picks the block and `props` fill it:

- `title` and `description` are the copy beside the code.
- `codeTabs` are the files, each with `label`, `value`, `language`, `code`, `fileName` and `fileIcon`. A tab without `code` is skipped.
- `copyAriaLabel` names the copy button for screen readers.
- `primaryAction` and `secondaryAction` are the two buttons. A button without a label or link is dropped.

Example:

<div className="sb-site-json">
  <Source of={CodeSplitStories.DefaultJson} dark />
</div>

### Accelerator

From the Application Accelerator page: a heading, a sentence and a text button on one side, a one-file code sample on the other. With one tab, the sample shows a filename bar and no tabs.

<Canvas of={CodeSplitStories.Accelerator} />

##### Use it on the site

Add this entry to the `sections` array of the page JSON. `_id` picks the block and `props` fill it:

- `title` and `description` are the copy on the start side.
- `codeTabs` are the files; one tab draws a filename bar instead of tabs.
- `action` is the text button. Without a label or link it is dropped.

### Recipes

From the Workloads page: a horizontal title opens the module, a three-file code sample sits on a faded texture, and three recipes run down the other side, one per file.

<Canvas of={CodeSplitStories.Recipes} />

##### Use it on the site

Add this entry to the `sections` array of the page JSON. `_id` picks the block and `props` fill it:

- `eyebrow`, `title` and `description` make the section title.
- `codeTabs` are the files of the sample.
- `recipes` are the steps beside the code, each a `title` and a `description`.

Example:

  <Source of={CodeSplitStories.RecipesJson} dark />
</div>
