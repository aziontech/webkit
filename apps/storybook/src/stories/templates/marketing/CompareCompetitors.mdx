# CompareCompetitors

A table that compares Azion with one competitor, capability by capability. It is used on the migration guide landing pages.

A tick means full support, a dash means none, and partial support is written out. Screen readers hear each value with its row and its column. The header row stays on screen while you scroll.

Built from `SectionModule` and `SectionTitle`, with `Brand` for the Azion column and the competitor logo for the other.

##### Use it on the site

Add this entry to the `sections` array of the page JSON. `_id` picks the block and `props` fill it:

- `eyebrow` and `title` head the section. `caption` names the table for screen readers.
- `competitor` sets the other column: `name`, `logo`, and `logoLight` for the light theme. Without a logo the name shows as text.
- `rows[]` holds one `capability` with an `azion` and a `competitor` level: `full`, `partial` or `none`. A missing level counts as `none`.
- `fullLabel`, `partialLabel` and `noneLabel` are the texts for each level.
