# FeatureScroll

A list of features with the product widget that shows each one. The band pins under the site header while the page scrolls; as the reader scrolls, the open feature moves on and the console widget beside it changes to match.

It is the sibling of `StickyScrollCode`: the same pinned band, with a console fragment in place of a code sample. Below `lg` it turns into a FeatureTiles grid: each feature becomes a tile, its widget drawn still over the title and description.

Built from `SectionModule`, `SectionTitle`, `FrameBox`, `StickyStack`, `TextureMaterial`, `Button`, `CardGrid`, `MediaTile` and the product widgets.

### Default

The Workloads band: five features, from the workloads list to gradual rollouts and rollback, each shown by its own console widget. Each feature carries its own docs button under its description, shown only while the feature is open.

##### Use it on the site

Add this entry to the `sections` array of the page JSON. `_id` picks the block and `props` fill it:

- `eyebrow`, `title` and `description` fill the section title.
- `items[]` are the features in reading order, each a `title` and a `description`.
- `items[].action` is the feature's own button, with `label` and `href`; it shows under the description while the feature is open.
- `items[].scene` is the widget: the `component` and the `props` it receives.
