# FeatureTiles

A row of reasons, each a picture over a short bold title and a sentence. Home uses it for "Why Azion", and Pricing for why its pricing works the way it does.

The tiles sit on a hairline frame grid with no padding, so the artwork runs to the rules.

Built from `SectionModule`, `FrameBox`, `CardGrid` and `MediaTile`, with `SectionTitle` for the heading and `Illustration` where the picture is a registered illustration.

### Artwork

Home's "Why Azion" band: an eyebrow, a title and a description over four tiles, each picture an SVG file passed to `MediaTile` as `src`.

<Canvas of={FeatureTilesStories.Artwork} />

##### Use it on the site

Add this entry to the `sections` array of the page JSON. `_id` picks the block and `props` fill it:

- `eyebrow`, `title` and `description` make the heading. Without a title the heading is left out.
- `tiles` are the reasons, each a `title`, a `description` and an `image` path with its `imageAlt`.

Example:

<div className="sb-site-json">
  <Source of={FeatureTilesStories.ArtworkJson} dark />
</div>

/>

### Illustrated

Pricing's band: three tiles with no heading, each picture a registered `Illustration`, scaled per tile and filling the tile's width.

<Canvas of={FeatureTilesStories.Illustrated} />

##### Use it on the site

Add this entry to the `sections` array of the page JSON. `_id` picks the block and `props` fill it:

- `tiles` are the reasons, each a `title`, a `description` and an `illustration` name with its `illustrationLabel`.
- The block sets each tile's scale itself, so there is nothing to size.

Example:

<div className="sb-site-json">
  <Source of={FeatureTilesStories.IllustratedJson} dark />
</div>
