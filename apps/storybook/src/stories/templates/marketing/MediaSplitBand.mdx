# MediaSplitBand

One claim beside one picture of it, in a band of its own, linked to the page that explains it. Solution pages use it for their reference architecture, and migration guides for the full guide.

Every band sits on the same small pixelate texture, fading toward the top. With one action the whole band is a link to the same place. With two, the band is not a link and the reader picks a button.

Built from `SectionModule`, a `framed` `MediaSplit`, `Illustration` and `Button`.

### Architecture

The reference-architecture band of a solution page: a title only, large and centered, the diagram on the canvas fill, and an outlined Docs action. Retail's copy.

<Canvas of={MediaSplitBandStories.Architecture} />

##### Use it on the site

Add this entry to the `sections` array of the page JSON. `_id` picks the block and `props` fill it:

- `title` is the band's only copy.
- `illustration` names the diagram and `illustrationLabel` describes it.
- `action` is the button; it opens in a new tab. Without a label or link it is dropped.

Example:

### Two actions

The Workloads runtime band with two actions: Docs as the secondary button and See GitHub as the outlined one, each with its own link. The band itself is not a link, so only the button under the pointer reacts.

<Canvas of={MediaSplitBandStories.TwoActions} />

##### Use it on the site

Add this entry to the `sections` array of the page JSON. `_id` picks the block and `props` fill it:

- `title` and `description` are the copy beside the art.
- `illustration` names the scene and `illustrationLabel` describes it.
- `primaryAction` and `secondaryAction` are the two buttons. The second keeps the GitHub icon and opens in a new tab. A button without a label or link is dropped.
