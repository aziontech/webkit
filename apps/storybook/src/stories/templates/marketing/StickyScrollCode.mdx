### Default

The "Everything You Need to Build and Deploy" band for the Web Apps page: five capabilities, from deploying with the CLI to querying metrics over GraphQL, each with a one-file code sample. The docs button sits under the sample from `lg` up and under the title below it.

##### Use it on the site

Add this entry to the `sections` array of the page JSON. `_id` picks the block and `props` fill it:

- `eyebrow`, `title` and `description` fill the section title.
- `action` is the docs button, with `label` and `href`.
- `items[]` are the capabilities in reading order, each a `title` and a `description`.
- `items[].code` is the one-file sample: `fileName`, `fileIcon`, `language` and the `code` itself.
