# UseCaseLinks

A titled grid of use cases that points at the ways a product is applied. Each cell is itself the link, so the band needs no buttons. Application Accelerator uses it.

Built from `SectionModule`, `SectionTitle` and `CardGrid kind="divider"`, with a `Topic` per cell.

### Topics

Six linked cells from the Application Accelerator page. Each cell shows an arrow on its headline because it has a link.

##### Use it on the site

Add this entry to the `sections` array of the page JSON. `_id` picks the block and `props` fill it:

- `title` is the headline of the section.
- `items[]` are the use cases in reading order; three fill a row.
- Each item takes an `icon` class, a `title`, a one-sentence `description` and the `href` the whole cell links to.
