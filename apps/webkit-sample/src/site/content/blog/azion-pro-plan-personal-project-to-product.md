At some point, the project that started as an experiment reaches a turning point. Someone wants to use it for real. A storefront prototype receives its first order. The chatbot you built to learn starts serving real users. That’s when the question changes: it’s no longer “What can I test?” but “My project is growing. What comes next?”

Pro is the next step for that stage. It lets you take what you built on Hobby into a commercial or production environment without moving to a different platform.

## What You Get With Pro

Pro provides the capacity and flexibility needed to run a commercial or production application:

- **Commercial and production use:** your project can start serving customers, processing orders, or supporting a live operation.
- **More included capacity:** workloads, requests, data transfer, storage, compute, and security resources come with higher included limits.
- **Flexibility to grow:** usage beyond the included limits is billed on demand.
- **More control over costs:** configurable spend limits help you monitor usage and define how far it can go.
- **Continuity on the same platform:** you can evolve the project you already built without migrating to another environment.

## What This Means for the Projects You’ve Already Started

Take any of the projects you can build on Hobby and see how they can evolve:

### From E-Commerce Prototype to Live Store

On Hobby, an e-commerce prototype can be used to test the catalog, design, and navigation flow without processing real sales. On Pro, the same application can process customer orders, with higher request and data transfer limits and on-demand usage to support changes in application traffic.

### From Personal Chatbot to Production Assistant

An agent you built to learn about RAG can evolve into a tool that serves real users. If usage exceeds the included limits, additional consumption is billed on demand.

### From Blog or Portfolio to a Growing Channel

If your blog or portfolio evolves into a commercial or production project, Pro provides higher included limits and on-demand usage to support traffic growth without requiring a move to another platform.

## How to Upgrade

Upgrading from Hobby to Pro takes effect immediately and lets you continue using the projects you’ve already created on the Azion Platform. You don’t need to migrate to another platform or rebuild your application. Downgrades and cancellations take effect at the end of the current billing cycle.

## When to Consider Enterprise

Pro can continue supporting your application as usage grows. However, when your operation reaches a higher and more predictable level of consumption, Enterprise can significantly reduce costs in exchange for a usage or spend commitment.

With Reserved Capacity, savings are tied to committing to a specific level of usage in advance. Savings Plan, in turn, offers more favorable pricing based on a spend commitment. Moving to Enterprise is therefore not a requirement at a certain scale, but an opportunity to optimize costs when your usage profile makes that commitment worthwhile.

## Quick Questions

**Do I need to migrate my code to use Pro?** No. The upgrade takes place within the Azion Platform and changes the account’s limits and usage terms.

**What happens to usage beyond the amount included with Pro?** Additional usage is billed on demand, with configurable spend limits to help keep costs predictable.

**Can I go back to Hobby after upgrading?** Yes. You can downgrade, and the change takes effect at the end of the current billing cycle.
