## What is Azion Real-Time Events?

[Real-Time Events](https://www.azion.com/en/products/real-time-events/) is Azion’s solution for tracking, analyzing, and querying events generated by applications, APIs, and security services. It was designed to deliver accurate and up-to-date information across different layers of your operation.   With Real-Time Events, you can:

- View events in near real time;
- Investigate failures, errors, and unexpected behaviors;
- Detect threats quickly;
- Correlate events from different sources in a single place;
- Run advanced queries for analysis and troubleshooting.

In distributed environments with increasingly sophisticated threats, fast decisions require reliable visibility — and the product delivers exactly that.

## How does Real-Time Events work?

Real-Time Events collects, organizes, and makes available the events generated by your applications and Azion services **practically in real time**. It operates in a simple and efficient way:

### 1. Automatic event capture

Real-Time Events continuously receives events in an automatic way, without requiring additional configuration from the user.

### 2. Organized into data sources

Each event type is organized into a specific [data source](https://www.azion.com/en/documentation/products/observe/real-time-events/#data-sources) — such as HTTP Requests, Functions, Tiered Cache, or DNS — enabling precise searches and detailed investigations.

### 3. Low-latency availability

Events become accessible quickly, allowing teams to identify unexpected behaviors, errors, and potential threats **close to real time**.

### 4. Seven-day retention with no sampling

All events are preserved for 168 hours — essential for performance analysis, debugging, and security incident investigations.

### 5. Query via Console or GraphQL API

You can explore data visually through the Azion Console or automate queries via GraphQL for integrations with SIEMs, internal pipelines, or custom dashboards.

## Key benefits of Real-Time Events

RTE was built to increase operational clarity, accelerate response times, and improve reliability in modern environments. Its main benefits include:

### 1. Complete data with no event loss

No event is discarded — even during high traffic — enabling more accurate analysis and audits.

### 2. Faster detection and response

With an average latency of approximately 40 seconds, errors, anomalies, and threats are identified almost immediately.

Events from applications, APIs, and security services are consolidated into a single product, simplifying correlation and reducing tool fragmentation.
