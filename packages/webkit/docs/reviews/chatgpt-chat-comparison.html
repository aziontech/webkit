The seven known gaps, after measuring

  • 1. Text rhythm Confirmed and measured. Answer text is 18/24.75 on desktop and 16/22 on a phone; ChatGPT is 16/26 at every width. Headings are the body size in ours, one step up in ChatGPT.
  • 2. Floating header Half confirmed. Our phone header uses filled square boxes with a shadow. Logged-out ChatGPT uses 44px white circles; logged-in ChatGPT uses plain 36px ghost buttons with no box at all.
  • 3. Foot of the thread Confirmed for the scroll-to-latest button (ChatGPT: blurred, translucent, soft 24px shadow, 0.18s fade). The fade above the composer needs the logged-in stylesheet, which the saved pages do not carry.
  • 4. Space between turns Reversed. Ours is now tighter: 24 on desktop and 16 on a phone, against ChatGPT's 36.
  • 5. Composer Confirmed. ChatGPT: 768 x 52, radius 28, three soft shadows, no visible focus ring. Ours: 844 x 58, radius 8, a dark border with a 2px ring at load (it opens focused), and an orange 40px voice button.
  • 6. Prompt actions Not a gap. Logged-in ChatGPT shows them on touch screens too (its CSS turns them on under hover:none).
  • 7. States never seen Now measured: prompt glides to the top after send (about 600 ms), no auto-scroll while streaming, each word fades in over 0.7 s, tables, maths, citations, inline badges. Still missing: images, errors, thinking shimmer, the keyboard-open phone.

Next steps, in order

  1. Text rhythm (one change, biggest win). Answer and prompt text 16px with a 26px line on every width; 16 between paragraphs; headings one step up (18/28 w600, 24 above, 8 below); list indent 32. Needs a chat reading style in DESIGN.md, which the owner approves.
  2. Column and composer width. Thread and composer 768 wide on desktop, composer 52 tall on one line, text 16/26 inside it.
  3. Action row. 20px icons in the muted text colour on 32px buttons with a 44px hit area; fold Good and Bad into one Feedback button and Try again into More, as ChatGPT does.
  4. Code. Inline code at 0.93em instead of 12px; code blocks at 14/22 with a 48px header and a tinted fill so they stand off the page.
  5. Scroll and streaming behaviour. On send, glide the new prompt to the top (about 600 ms) and reserve space below; do not follow the stream; fade each new word in over 0.7 s, off under reduced motion; a scroll-to-latest button with blur, a soft shadow and a 0.18s fade.
  6. Side panel. Collapse the history to an icon rail instead of hiding it, sliding the thread with a 0.22s ease. In the console, start the history closed below 1440 wide so the chat keeps a 768 column next to the console nav.
  7. Rich answers. Check tables (no frame, 1px rules, 14/20 cells), maths (KaTeX) and citation chips (20 tall, 100 max) inside real answers, and add them to the block's examples.
  8. Dark composer. No white border at rest in dark; keep the surface and blur.

Steps 1 to 8 are fixes with no brand conflict. They go to one lane that owns the whole chat screen (spec first, then tests, examples, budgets, baselines), after the questions below are answered.

Questions for the owner

Answer with a letter for each; every answer becomes a DECISIONS.md row (CHAT-2 onward).

  1. Composer shape. A: keep 8px corners (brand rule). B: chat exception, fully round ends (radius 28) for the composer only.
  2. Focus ring at load. The chat opens with the cursor in the composer, so the 2px focus ring is the first thing people see. A: keep the ring (current accessibility rule). B: show only the caret and a slightly darker border when the composer is focused, and keep the ring for keyboard focus on buttons.
  3. Floating header buttons on a phone. A: plain ghost buttons with no box, as logged-in ChatGPT does (no brand clash). B: round translucent buttons as logged-out ChatGPT does (needs the chat exception).
  4. Voice button. A: keep the orange filled button. B: a neutral filled circle that turns into Send when there is text, as ChatGPT does; orange stays for the primary action elsewhere.
  5. Bubble, code block and chip corners. A: keep --shape-card and --shape-control. B: chat exception, larger radii inside the chat only: bubble 20, code block 16, citation and badge chips fully round.

Limits of this round

  • Logged out, ChatGPT serves a lighter site: no prompt editing, no feedback menus, no Try again row, no thinking shimmer. Those rows are marked Not measured.
  • The saved logged-in pages came without most of their stylesheets, so their tables, headings and the fade above the composer could not be measured; their layout, bubble, composer and action rows could.
  • Prompts 7 to 12 of the spec (edit, Try again, Stop, feedback menus, the + menu, voice) need a logged-in session. Stop was checked: it takes the send button's slot.
  • Screenshots stay outside git; the owner's saved conversations are not shown here.
