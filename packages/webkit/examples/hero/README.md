# Hero

The opening band of a marketing page. It holds the page h1 and its main actions, full width above the page column, framed by a backdrop, a client strip or an illustration.

`Hero` is the primitive the page heroes compose. The ready-made site bands, with their page JSON, live with the sections that ship them: the centered, title-band, pixel-floor and copy-beside-art heroes in [`hero-band`](../hero-band/README.md) (`@aziontech/webkit/hero-band`), and the Workloads hero in [`hero-copy-on-top-art`](../hero-copy-on-top-art/README.md) (`@aziontech/webkit/hero-copy-on-top-art`).
