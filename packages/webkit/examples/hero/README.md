# Hero

The opening band of a marketing page. It holds the page h1 and its main actions, full width above the page column, framed by a backdrop, a client strip or an illustration.

`Hero` is the primitive the page heroes compose. The ready-made site bands, with their page JSON, live with the sections that ship them: the centered, title-band, copy-beside-art and copy-on-top-art heroes, the Workloads topology and the opening with an argument grid, all in [`hero-section`](../hero-section/README.md) (`@aziontech/webkit/hero-section`).
